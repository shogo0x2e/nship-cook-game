# SQLite → Google Sheets（30分ごと）

SQLiteを正本にして、送信済みの通常回答だけを読み取り専用APIからGASで取り込みます。
回答者の秘密キー・認証テーブル・デモ回答・途中保存は出力しません。
`回答一覧` は1回答1行、`項目説明` に内部キーと選択肢、`更新状況` に最終更新時刻と回答数を表示します。
分析用の計算やグラフは別のタブに置いてください。同期は上記3タブだけを書き換えます。

## サーバー

API: `GET /api/operator/survey-snapshot`。`Authorization: Bearer <64桁のhex鍵>` が必要です。
`DATA_DIR/survey-export-token` がなければAPIは無効（404）。鍵は256bitの乱数で生成し、所有者1000:1000・0600で配置します。
配置／変更後はコンテナを再作成または再起動してください。鍵はGitやイメージに含めません。
公開の回答一覧APIは設けません。専用キーを削除して再起動すれば同期アクセスを失効できます。
クエリパラメータの鍵や、通常のアカウント・回答者キーは使用できません。

## スプレッドシートに紐づくGAS

1. 対象のシートで「拡張機能 → Apps Script」を開き、`Code.gs` の内容を保存。
2. 「プロジェクトの設定 → スクリプト プロパティ」に `COOKGAME_EXPORT_TOKEN` を保存。
3. `installCookgameSync` を1回実行し、このスプレッドシートの読み書き・外部HTTP通信・トリガー管理の権限を承認。
4. 実行成功後、「トリガー」で `syncCookgameResponses` の時間主導トリガーが1つあることを確認。
5. シートを再読み込みすると「回答データ」メニューから手動更新・停止もできます。

`@OnlyCurrentDoc` により、このスクリプトのスプレッドシート権限は紐づくシートに限定します。
Google側にコピーされた回答は、このシートとGASを編集できる人に見えるため、共有相手を限定してください。
GASはブラウザやMacを閉じても実行されます。厳密な毎時00分・30分の実行保証ではなく、30分間隔です。
同時実行をロックし、取得・認証・形式検証に失敗した場合は既存データを消しません。
自由記述が数式として実行されないよう、シートへ書く際に文字列として扱います（SQLite原文は変更しません）。

検証: `npm test`（認証・通常回答限定・秘密情報の除外・GASの失敗時保持・数式無効化）。
